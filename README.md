猫邻 · 离线展示与源码包

给查看者
1. 先解压整个压缩包。
2. 双击根目录“打开网站.html”，用电脑 Chrome、Edge 等浏览器打开。
3. 不要直接在微信/压缩软件的预览窗口中打开；请下载、解压后打开。

无需 Python、Node、数据库、账号、分享口令或服务器。查看时不依赖发件人的电脑，也没有临时网址到期问题。
网页已嵌入样式、脚本和两张示例猫咪照片，可单独转发这个 HTML 文件。

内容包括：猫咪档案、社区动态、猫咪照护、活动与求助、志愿者与团队、我的。
本包使用示例资料，不包含线上社区数据、真实账号、私人照片或联系方式。
猫咪查询使用手动选择，不运行 AI。活动和团队尚无内容时显示空状态。
允许体验的交互只保存在当前浏览器，不会上传、同步或联系任何人。

给接手源码的人
“源码/dist/”是整理后的 HTML、CSS、JavaScript 与静态图片；仅包含前端。
“源码/scripts/build_portable.py”是单文件构建脚本，修改源码后可在“源码”目录运行：
python scripts/build_portable.py
构建结果位于“源码/releases/猫邻免安装版/打开网站.html”。只有重新构建的人需要 Python，普通查看者不需要安装任何东西。
如需放到静态托管平台，上传根目录的“打开网站.html”并命名为 index.html；它在 HTTP/HTTPS 下同样不请求后端。

包内没有 Supabase 密钥、ngrok/Pinggy 令牌、本地配置、Git 历史、模型文件或服务器代码。
离线展示不等于线上多人协作系统；要恢复账号和共享数据，需另行接入后台。
