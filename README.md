# 猫邻动态优化版

该版本保留队友原版的页面结构、信息内容和本地交互，重点增强视觉层次与动态反馈。

## 主要改动

- 固定导航、滚动进度与滚动后的导航层次变化
- 首页标题遮罩入场、图片开窗、状态卡浮层和照护流程横向卡片
- 导航切换使用浏览器 View Transitions，页面进出带方向感
- 按钮波纹、按压缩放、悬停位移与箭头响应
- 猫咪卡片和照护卡片的轻微跟随倾斜与悬浮层次
- 页面区块和卡片进入视口时错峰出现
- 支持 `prefers-reduced-motion`，减少动态时不会隐藏内容

## 本地运行

```powershell
python -m http.server 4327 --directory dist
```

然后打开 `http://127.0.0.1:4327`。

## 检查

```bash
npm run check
```

## 说明

当前页面仍为离线前端原型，互动数据只保存在当前浏览器。新增动态效果仅用于呈现和交互演示，没有增加远程依赖。
