# 猫邻 maolin

猫邻是一个以校园与社区流浪猫为对象的关爱协作网站原型。页面视觉延续浅黄绿背景、深森林绿文字、橄榄绿操作色、细线、弧形照片和编辑式排版。

## 页面结构

首页：

- 主标语“让每一份关爱，都有迹可循”；
- 一张社区猫主视觉；
- 一个进入平台的功能框；
- 三张社区近况图片入口。
- 不再显示顶部模块导航，进入功能中心后才展示五个入口。

功能中心：

1. 猫咪档案；
2. 社区猫咪与论坛；
3. AI 拍照识别与喂养助手；
4. 救助与社区协作；
5. 个人中心。

每张卡片包含封面、标题、两行简介、标签和“查看”按钮。

响应式布局：

- 电脑 3 列；
- 平板 2 列；
- 手机 1 列。

## 已有功能

- 猫咪列表、搜索、筛选、档案详情和关注；
- 社区动态、照片发布、点赞和评论；
- 浏览器内图片相似度演示、人工确认和喂养记录查询；
- 新增的救助任务列表、任务认领、求助发布和救助记录；
- 个人资料、任务统计、照护记录和 JSON 导出。

## 本地运行

```powershell
.\启动网站.ps1
```

然后打开：

<http://127.0.0.1:4317>

也可直接运行：

```bash
npx --yes serve@14.2.4 dist -l 4317 --no-clipboard
```

## 检查

```bash
npm run check
```

该命令会检查所有前端 JavaScript 模块的语法。

## 能力边界

- 新动态、评论和任务认领只保存在当前浏览器 localStorage；
- 照片比较使用差值哈希和平均颜色，不是生产级 AI；
- 不能根据照片判断猫咪是否吃饱或是否需要立即投喂；
- 示例内容不代表真实社区排班、医疗判断或救助结果；
- 正式上线仍需要服务器、账号体系、内容审核和数据同步。
