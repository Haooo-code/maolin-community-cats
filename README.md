# 猫邻整合版

这一版保留原首页的“主标语、进入框和五模块功能中心”，内部功能采用队友 2026 年 10 月 28 日源码包中的猫咪档案、社区动态、照护助手、活动求助、志愿者与个人中心。

## 页面结构

- `#home`：主界面与进入框
- `#modules`：五张功能卡片
- `#cats`：猫咪档案
- `#community`：社区动态
- `#recognize`：照片查找与喂养记录
- `#opportunities`：救助与社区协作
- `#volunteers`：志愿者与团队
- `#me`：个人中心

## 本地运行

```powershell
.\启动网站.ps1
```

然后打开 `http://127.0.0.1:4324`。

## 检查

```bash
npm run check
```

## 能力边界

- 当前为离线前端展示版，没有账号、云端数据库或多人实时同步。
- 新增猫咪、动态、评论、关注与照护记录只保存在当前浏览器。
- 照片查找采用离线人工核对流程，不运行生产级 AI 猫脸识别。
- 页面不根据照片判断猫咪是否吃饱、是否患病或是否需要投喂。
